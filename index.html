PROYECTOS TÉCNICOS EN PRODUCCIÓN

1. Automatización de Procesos de Inventario y Abastecimiento (Puntos de Reorden — ERP SIESA)
Tecnologías: Node-RED, ERP SIESA, SOAP, XML, SQL Server, Power Automate Desktop, Power BI

Problema: Revisión semanal manual de inventarios críticos mediante Excel y digitación individual en el ERP (~3 horas semanales dedicadas por el responsable).
Solución: Automatización en producción desde el 21 de julio de 2025. V1 en Power Automate Desktop que evolucionó a V2 directa en Node-RED con endpoints, consumo de servicios SOAP de SIESA, inyección de XML, SQL Server y Power BI.
Resultado: Reducción del tiempo de ~3 horas semanales a menos de 1 minuto 9 segundos por ejecución diaria (7:00 a.m.). 1.175 documentos generados trazados y auditados en Power BI.

2. Sistema de Programación y Gestión de Turnos (Turnia Operarios — 12 Horas)
Tecnologías: JavaScript, HTML5/CSS3, Algoritmo de Rotación, API HikCentral Facial, Backend

Solución: Desarrollo desde cero (frontend, backend y algoritmos) en producción desde el 27 de septiembre de 2025. Incluye algoritmo de asignación de rotaciones de 12 horas, módulo de novedades (vacaciones, incapacidades) e integración con API HikCentral de marcación facial.
Resultado: Cobertura de ~143 colaboradores en 11 áreas con ~22 usuarios directos y ~10 supervisores. Generación estructurada de mallas y contraste en tiempo real de presencia física vs. programación planificada.

3. Automatización de Contabilización de Documentos (Facturas de Proveedores — ERP SIESA)
Tecnologías: Node-RED, SOAP UI, Power Automate, SQL Server, SharePoint, ERP SIESA

Solución: Versión 2 en producción desde marzo de 2026. Orquestación directa en Node-RED que cruza entradas de almacén, órdenes de compra y facturas con validación de reglas contables e impuestos en SIESA, apoyando el proceso de factura electrónica.
Resultado: 1.168 documentos procesados (FDP, FIA, FIA Anticipo, FDS, FAC). Muestra auditada de 603 documentos con 538 completamente exitosos (las 65 anulaciones correspondieron a pruebas y soporte).

4. Integración de Solicitudes y Trazabilidad Operativa (RQC / GelcoInfo)
Tecnologías: SIESA ERP, GelcoInfo, Node-RED, SQL Server, Power Automate, Power BI Embedded, HTML

Solución: Conexión bidireccional entre SIESA y aplicación interna para procesar requisiciones de almacén y salidas de insumos (PTAR, SST, paqueteo, mezclas) con flujo de aprobaciones y reportes embebidos.
Resultado: Atención fluida de 40 a 50+ solicitudes diarias con trazabilidad total, mitigando aproximadamente 2 horas diarias de trabajo operativo manual.

5. Integración y Automatización del Proceso de Facturación (Máquina Vending de Colágeno)
Tecnologías: API REST del Proveedor, Web App (IndexedDB), Node-RED, SOAP SIESA, Facturación Electrónica

Solución: En producción desde mayo de 2026. Flujo integrado desde la API de la máquina dispensadora, interfaz web con IndexedDB para validación de entregas, Node-RED, causación SOAP en SIESA y facturación electrónica con Power Automate Desktop.
Resultado: 835 documentos FVP generados e integrados al proceso de facturación electrónica.

6. Sistema de Gestión y Trazabilidad de Entrega de Almuerzos (Gestor de Almuerzos)
Tecnologías: MongoDB (NoSQL / JSON), Node-RED Backend, API HikCentral Facial

Solución: Proyecto desarrollado conjuntamente. Responsable de la lógica de negocio, backend en Node-RED, modelado en MongoDB (colecciones, registros y vistas) e integración con la API de reconocimiento facial de HikCentral.
Resultado: Cobertura de ~266 colaboradores activos y 90–100 usos diarios de lunes a viernes, garantizando conteo y trazabilidad exacta en tiempo real sin planillas físicas.
