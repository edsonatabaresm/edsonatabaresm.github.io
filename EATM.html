Automatización RPA • ERP ● En Producción

1. Solicitudes de Puntos de Reorden (SPR)

Detección automática de ítems con inventario crítico y generación directa de Solicitudes de Puntos de Reorden en el ERP SIESA, sustituyendo un proceso manual en hojas de cálculo Excel.

Impacto: Reducción de ~3 horas semanales a menos de 1:09 min por ciclo. +1.175 órdenes trazadas en Power BI.
Node-RED ERP SIESA SOAP / XML SQL Server Power BI
Desarrollo Full Stack • Biometría ● En Producción

2. Software de Gestión de Turnos de Planta (12h)

Aplicación desarrollada desde cero con algoritmo de secuencias de rotación para personal de planta en turnos de 12 horas, gestión de novedades e integración con reconocimiento facial.

Impacto: Generación estructurada de turnos y comparación de programación planificada vs. presencia física real con HikCentral.
JavaScript Algoritmo de Rotación API HikCentral Base de Datos
Automatización RPA • Finanzas ● En Producción

3. Contabilización Automática de Facturas

Orquestación integral para contabilizar facturas de proveedores: cruce de entradas de almacén, órdenes de compra, validación de reglas impositivas y causación automática en SIESA.

Impacto: 1.168 facturas procesadas desde marzo 2026. Muestra auditada de 603 documentos con 538 completamente exitosos.
Node-RED SOAP UI ERP SIESA Power Automate Web SQL
Integración ERP • GelcoInfo ● En Producción

4. Automatización de Doble Digitación (RQC)

Conexión bidireccional entre SIESA y GelcoInfo para procesar requisiciones y salidas de almacén (EPP, PTAR, paqueteo, mezclas) con aprobaciones y reportes embebidos.

Impacto: Procesa 40 a 50+ requisiciones diarias con trazabilidad completa, mitigando ~2 horas diarias de digitación repetitiva.
SIESA • GelcoInfo Node-RED Power Automate SQL Server Power BI
Frontend • APIs • Facturación ● En Producción

5. Facturación Automática de Máquina Vending

Consumo de la API del dispensador de colágeno, interfaz HTML con almacenamiento local en IndexedDB para verificación de entregas y causación fiscal electrónica automática.

Impacto: Digitalización y facturación sin intervención humana desde la dispensación física hasta el comprobante fiscal.
API REST HTML / IndexedDB Node-RED SOAP SIESA Facturación Electrónica
Backend • NoSQL • Reconocimiento ● En Producción

6. Gestor y Control de Entrega de Almuerzos

Backend en Node-RED con almacenamiento en MongoDB NoSQL integrado a la API de reconocimiento facial de HikCentral para control y conteo exacto de servicios de alimentación.

Impacto: Registro fidedigno en tiempo real, eliminación de planillas de papel y trazabilidad auditada de colaboradores atendidos.
MongoDB NoSQL Node-RED Backend API HikCentral Facial JSON / Vistas
